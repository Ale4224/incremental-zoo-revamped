	- Changes by Robert Munafo:
 20190825 Explicitly show the formula behind birth/death rates; add
debug1/debug2 elements (for figuring out birth/death rate formulas)
 20190829 Add IZ.buyRequire function to auto-generate text "NNN
<animal> are needed to buy <animal>". Add IZ.fmt function to format
large numbers with K, M, B, T abbreviations. Add IZ.commas function to
turn 12345 into 12,345. Obfuscate contact email addresses. Display
birthrate formula even when owning only 1 animal
       . Replace "discovered" with "learned how to care for" animals.
Replace "Reduce the wait" with "Invest in animal welfare science".
         Fix several bugs with fines: if you have a lot of money it simply
takes the money rather than putting you in debt ("garnishment"), if not
munch money it takes some animals instead.
 20190902 "You must have NNN <animals>" is now required only for the
first time you buy the new species.
         Add needSave and IZsetSave for faster auto-saves when it's important.
         Credit limit now always based on biggest owned animal.
         Reset is now "new zoo", requires zero debt, and current zoo must have
at least 6 species.
         Animal exchange offer can no longer be re-rolled by reloading
the page.
         Replace "many flamingos" picture with a "single flamingo"
picture. Images are now in "img/" subdirectory.
         "Enclosures" are now called "habitats".
 20190904 Show birth/death rate formulas in tooltext.
 20190905 Buying time now gives a random amount of time. Add alerts to
explain why you can't buy the 21st birth rate / death rate / higher
prices.
 20190906 Fix hyperexponential debt bug (replace
"debt=Math.pow(debt,1.00002)" with "debt=debt*1.00015"). Now the
interest rate is the same for all borrowers, rather than being higher
for big borrowers. The old and new are equivalent when the debt is
1.00015^(1/0.00002) = $1807.03. Also, auto-forgive debt below $0.01.
 20190908 "New zoo" now requires 12 species the first time (and 6
species all subsequent times)
 20190914 Change a few quotes.
 20190915 Display "pays for itself" amounts for "but visitors" and
"get visitors more frequently".
 20190918 Visitor costs now both escalate more slowly (1.2 instead of 1.25)
making visitors relevant for a longer portion of mid-game (but still useless
in endgame).
 20191102 Add IZ.bigbucks and clean up the stats formatting a bit.
